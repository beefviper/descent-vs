# Original build variants

The original DOS build was driven by Watcom `wmake` makefiles that included
`makefile.def` (not part of the source release) and a per-variant `.ini`
settings file from `main/`. Those files have been removed from this tree; this
page records what they configured so the information is not lost.

Every library and the game itself were compiled with:

    NETWORK RELEASE NDEBUG

`main/vers_id.h` was generated by the build from the selected `.ini` file and
defines `VERSION_NAME` and `VERSION_TYPE`. The copy in the tree is the one
generated for the default registered build (`inferno.ini`).

Settings common to all release variants:

| Setting           | Meaning                                                   |
|-------------------|-----------------------------------------------------------|
| `RELEASE_VERSION` | Turn off test, cheat and debugging functions              |
| `NMONO`           | No monochrome-display debug output                        |
| `NDEBUG`          | Debugging off (removes `Assert`, `Int3`, ...)             |
| `OPTIMIZE_ON`     | Build optimized                                           |

| Settings file  | `VERSION_NAME`                                        | Extra settings                              |
|----------------|-------------------------------------------------------|---------------------------------------------|
| `inferno.ini`  | Registered v1.5 Jan 5, 1996                           | (default build)                             |
| `dreg.ini`     | Registered v1.5 Jan 5, 1996                           |                                             |
| `drock.ini`    | Registered v1.5 Jan 5, 1996                           | `ROCKWELL_CODE`                             |
| `d4rent.ini`   | Descent Rental v1.5 Jan 5, 1996                       | `REQUIRE_CD` (copy protection), `USE_CD`    |
| `dsat.ini`     | Destination Saturn v1.5 Jan 5, 1996                   | `DEST_SAT`, `REQUIRE_CD`, `USE_CD`          |
| `dsatsg.ini`   | Destination Saturn v1.5sg Jan 5, 1996                 | `DEST_SAT`, `REQUIRE_CD`, `USE_CD`, `SIMULEYES` |
| `dsatup.ini`   | Destination Saturn Registered v1.5 Jan 5, 1996        |                                             |
| `dsatsgup.ini` | Destination Saturn Registered v1.5sg Jan 5, 1996      | `SIMULEYES`                                 |
| `dedit.ini`    | Editor v1.4a Jan 5, 1996                              | `EDITOR` (not a release build)              |

`SIMULEYES` (StereoGraphics glasses) is not referenced anywhere in the
released sources.
